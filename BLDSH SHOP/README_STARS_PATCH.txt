Важно:
1. В проекте должен существовать accounts/relayer.session.
2. Если его нет, один раз запусти:
       python make_relayer.py
   и авторизуй Telegram-аккаунт, на который покупатели отправляют подарки.
3. В этом патче НЕ содержится .session и НЕ содержатся токены.
4. Listener принимает обычные Star Gifts на 15/25/50/100 Stars.
5. Несколько подарков складываются в одну активную заявку пользователя.
6. Один и тот же входящий gift-message повторно не зачисляется.
